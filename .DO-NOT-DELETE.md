# DO NOT DELETE - Critical Assets

## Protected Files and Folders

The following files and folders are **CRITICAL** to the application and must NOT be deleted during cleanup:

### 1. **client/src/assets/** (formerly attached_assets/)
- Contains all competition photos and logos used throughout the site
- **Files inside:**
  - `nrsf-logo_1761313307811.jpg` - Main NRSA logo
  - `photo_2025-10-24_14-56-46_1761314282906.jpg` through `photo_2025-10-24_14-57-38_1761314282905.jpg` - 11 competition photos
  
- **Used in components:**
  - `Header.tsx` - Logo
  - `Footer.tsx` - Logo
  - `AdminLayout.tsx` - Logo
  - `Hero.tsx` - 4 hero images for background carousel
  - `HeroCarousel.tsx` - All 11 images for main carousel

### 2. **@assets Alias Configuration**
Must be present in both:
- `vite.config.ts` - Main build configuration
- `server/vite.ts` - Development server configuration

```typescript
resolve: {
  alias: {
    "@": path.resolve(__dirname, "client", "src"),
    "@shared": path.resolve(__dirname, "shared"),
    "@assets": path.resolve(__dirname, "client", "src", "assets"), // REQUIRED
  },
},
```

### 3. **Other Protected Folders**
- `client/public/` - Public static assets
- `shared/` - Shared types and schemas
- `server/` - Backend server code
- `migrations/` - Database migrations
- `.git/` - Version control

## What CAN Be Deleted

Safe to remove during cleanup:
- Markdown files with AI conversation logs (CRITICAL_FIXES_*.md, DEPLOYMENT_*.md, etc.)
- Temporary SQL files that are already applied
- Test scripts (test-*.js, check-*.js) after verification
- Duplicate config files with timestamps
- `.local/` directory (build cache)
- Debug log files

## Recovery Instructions

If `client/src/assets/` is accidentally deleted:

1. Restore from GitHub backup:
   ```bash
   git checkout HEAD -- client/src/assets/
   ```

2. Or copy from nrsaweb-main backup:
   ```bash
   Copy-Item -Path "nrsaweb-main/attached_assets" -Destination "client/src/assets" -Recurse -Force
   ```

3. Ensure @assets alias is in vite.config.ts and server/vite.ts
